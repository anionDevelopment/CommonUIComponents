# Release notes

## Changes

- the repository-address of the product points to the repository "anionDevelopment/CommonUIComponents" instead of to the former repository "anionDev/NgxCultureSelector", which does not exist anymore. This fixes the links to the repository and the example-pictures in the readmes of the published packages
- all packages (flutter and angular) link to the repository "anionDevelopment/CommonUIComponents" as repository, homepage and issue-tracker
- the packages "mat_country_selector" and "mat_culture_selector" require Flutter 3.32 or newer instead of Flutter 3.24 or newer, because the required Dart-version 3.8 is shipped with Flutter 3.32 for the first time
