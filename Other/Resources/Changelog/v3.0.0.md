# Release notes

## Changes

- The components which were developed in one repository each are now developed in this one: `MatCountrySelector`, `MatCultureSelector`, `MatDarkmodeToggleButton`, `NgxCountrySelector`, `NgxCultureSelector` and `NgxDarkmodeToggleButton` are code-units of it, and the history of every one of those repositories is part of the history of this one
- Every code-unit carries its own readme and its own example-pictures, so it documents itself wherever it is used
- The published packages are unchanged: every code-unit is still built and published as the package it was published as before
