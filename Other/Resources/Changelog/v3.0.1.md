# Release notes

## Changes

- Fix
- the unit-tests of the components are executed by Vitest instead of by Karma and Jasmine, because Karma is not the test-runner the Angular-team develops against anymore. The tests now run in "jsdom", so no browser has to be installed on the build-host anymore. The test-coverage is still written as a cobertura-file with the same structure as before, because the coverage-provider "istanbul" uses the same library to write it which Karma used
- the country-selectors (angular and flutter) show no flag for a country-code which consists of two characters but not of two letters, instead of showing two arbitrary symbols
