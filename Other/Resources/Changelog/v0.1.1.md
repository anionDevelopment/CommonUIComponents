# Release notes

## Changes

- `NgxCountrySelectorComponent` lets the user choose a country and emits the two-letter-code of that country via `countrySelected`
- The component brings the countries of ISO 3166-1 with it (`allCountries`); an application which offers only some countries passes its own list
- A country is shown as its flag and its english name, and `mat-select` finds an option by the letters which are typed while the list is open
- The flag is derived from the country-code (two regional-indicator-letters) instead of being shipped as a picture
- The package is publishable to npmjs.com as `@aniondev/ngx-country-selector` and contains a demo-application which shows the component
- Visual-regression-tests (playwright, chromium/firefox/webkit) cover the closed and the opened state of the component
