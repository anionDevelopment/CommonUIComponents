# Release notes

## Changes

- The build of the codeunit only builds the codeunit again: the packing of the published package is not implemented in this repository anymore but is left to ScriptCollection
- The git-ignore-rules of the codeunit are now defined in the codeunit instead of in the repository
- Added the readme of the codeunit, which is also the readme of the published package, and reduced the readme of the repository to the overview of the product
- Corrected the documentation of the build and removed `cyclonedx` from the required tools, which is not used by this codeunit
- Added testcases for `SharedPreferencesThemeModeStore`, which is the store every application gets by default and which was not covered by a testcase before
