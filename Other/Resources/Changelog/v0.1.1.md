# Release notes

## Changes

- `MatCountrySelector` lets the user choose a country and reports the two-letter-code of that country via the callback `onCountrySelected`
- The widget brings the countries of ISO 3166-1 with it (`allCountries`); an application which offers only some countries passes its own list
- A country is shown as its flag and its english name, and the list can be filtered by typing that name
- The flag is derived from the country-code (two regional-indicator-letters) instead of being shipped as a picture
- The package is publishable to pub.dev as `mat_country_selector` and contains an example-application which shows the widget
- Visual-regression-tests (golden-tests which run in a container) cover the closed and the opened state of the widget
