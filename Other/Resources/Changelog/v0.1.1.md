# Release notes

## Changes

- Fixed the gitignore-configuration of the repository: `build/` ignored the folder `MatCultureSelector/Other/Build` as well (git matches ignore-patterns case-insensitively on windows), so the build-script of the code-unit was never added to the repository. The dart- and flutter-specific ignores now belong to the code-unit, the repository-level ignores to the repository.
- The build puts the readme of the code-unit as well as the license and the changelog of the repository into the package which is published to pub.dev, using the corresponding options of ScriptCollection instead of an own implementation in `Build.py`. The hand-maintained `CHANGELOG.md` of the package was removed, because it is generated from the changelog of the repository now.
- Added a readme for the code-unit, which is what pub.dev shows on the page of the package. The readme of the repository now describes the product and refers to it for the usage of the widget, so that both descriptions can not drift apart.
