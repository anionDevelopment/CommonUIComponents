# Release notes

## Changes

- Initial release
- `MatCultureSelector` lets the user choose a culture from a configurable list of cultures and reports the choice via the callback `onCultureSelected`
- The package is publishable to pub.dev as `mat_culture_selector`
- The package contains an example-application which shows the widget
- Visual-regression-tests (golden-tests which run in a container) cover the closed and the opened state of the widget and also produce the example-pictures of the readme
- The repository implements the common project structure and is buildable with `scbuildcodeunits`
