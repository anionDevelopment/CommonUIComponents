# Release notes

## Changes

- Initial version of `mat_darkmode_toggle_button`: a flutter-widget which lets the user choose the color-scheme of an application between the three modes `system`, `light` and `dark`
- The package consists of `MatDarkmodeController` (holds the chosen mode and stores it in an exchangeable `ThemeModeStore`), `MatDarkmodeScope` (provides the controller to the widgets below it and applies the mode via `MaterialApp.themeMode`) and `MatDarkmodeToggleButton` (the control itself)
- The repository implements the common project structure with one codeunit `MatDarkmodeToggleButton`, including the build-, quality-check- and reference-scripts
- Added unit-tests as well as visual-regression-tests which compare a screenshot of a demo-page with a baseline-image inside a container, and which also generate the two example-images of the readme
- The build creates the folder which is published to pub.dev and verifies it with `dart pub publish --dry-run`; its readme, license and changelog are generated from the files of the repository
- Added a demo-application which shows the widget
