# Release notes

## Changes

- Replaced the dropdown by a three-state-control which offers the modes system, light and dark at the same time
- Switched the theming to the Material-3-theming-API: the mode is applied by the css-property "color-scheme" instead of by a second theme
- The chosen mode is now stored in the localStorage and is therefore kept over reloads and sessions
- The mode "system" now follows a change of the system-preference without a reload of the page
- Made the component usable with server-side-rendering and prerendering
- Updated to Angular 19 and Angular Material 19
- The package is now built as an angular-library instead of as an application
- The repository now implements the common project structure and is buildable with "scbuildcodeunits"
