# How to build

This codeunit is an Angular-library which is built with `ng-packagr`, including its unit-tests written in TypeScript.

The build-result is the npm-package in `Other/Artifacts/BuildResult_NPMPackage`. It is published under the name `@aniondev/ngx-darkmode-toggle-button`, while the component it contains is used as `<ngx-darkmode-toggle-button />`.
