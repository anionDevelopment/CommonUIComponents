# NgxCountrySelector

## Purpose

`ngx-country-selector` is an angular-component which lets the user choose a country, shown with its flag and its english name.

## Idea

Almost every application which asks for a country asks for the same list: the countries of ISO 3166-1. So this component brings that list with it instead of asking the application for it - an application which wants a country-selector binds nothing but the output. An application which offers only some countries (the countries it ships to, for example) passes its own list.

What the chosen country *means* stays the application's business: the component emits the two-letter-code of the country the user chose and does nothing else with it.

The flags are not pictures. A flag-emoji is the two letters of the country-code written as regional-indicator-symbols, which every system draws itself - so nothing has to be licensed, nothing has to be updated when a flag changes, and a system which does not know a flag simply shows the two letters.

A country is found by typing its name: `mat-select` jumps to the option whose text starts with the typed letters while the list is open, which is what keeps a list of almost 250 entries usable.

It is the angular-counterpart of [mat_country_selector](https://pub.dev/packages/mat_country_selector), which offers the same thing for flutter-applications.

## Requirements

- Angular 22
- Angular Material 22 (the component is built on `mat-select`)

## Installation

The package is published at [npmjs.com/package/@aniondev/ngx-country-selector](https://www.npmjs.com/package/@aniondev/ngx-country-selector).

```
npm install @aniondev/ngx-country-selector
```

## Usage

### 1. Include the theme once

The component is built on Angular Material, so the application has to include a Material-3-theme exactly once in its `styles.scss`:

```scss
@use '@angular/material' as mat;

html {
  color-scheme: light dark;
  @include mat.theme((color: mat.$azure-palette, typography: Roboto, density: 0));
}
```

### 2. Use the component

The component is standalone, so it is imported directly by the component which shows it. Without a list of countries it offers every country there is:

```typescript
import { Component } from '@angular/core';
import { NgxCountrySelectorComponent } from '@aniondev/ngx-country-selector';

@Component({
  selector: 'app-address-form',
  imports: [NgxCountrySelectorComponent],
  template: `<ngx-country-selector (countrySelected)="onCountrySelected($event)" />`,
})
export class AddressFormComponent {
  protected onCountrySelected(country: string): void {
    // for example: store "DE" as the country of the address
  }
}
```

An application which offers only some countries passes its own list:

```typescript
import { NgxCountry } from '@aniondev/ngx-country-selector';

protected readonly countriesWeShipTo: NgxCountry[] = [
  { code: 'DE', name: 'Germany' },
  { code: 'AT', name: 'Austria' },
  { code: 'CH', name: 'Switzerland' },
];
```

```html
<ngx-country-selector [countries]="countriesWeShipTo" (countrySelected)="onCountrySelected($event)" />
```

### 3. Parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `countrySelected` | `output<string>` | (output) | Emits the `code` of the country the user chose, for example `'DE'`. |
| `countries` | `readonly NgxCountry[]` | `allCountries` | The countries the user can choose from, in the order they are offered. Their `code`-values have to be distinct. |
| `selectedCountry` | `string \| undefined` | `undefined` | The `code` of the country which is preselected. |
| `label` | `string` | `'Country'` | The label of the control itself. Set it to a translated text if the application is localized. |

`NgxCountry` describes one country: its `code` (the two-letter-code of ISO 3166-1) and its `name` (the english name). `allCountries` is the list of all 249 of them, ordered by their english name; `flagOf(code)` and `labelOf(country)` are the two functions which turn a country into what is shown for it.

The component does not apply the chosen country anywhere itself and knows nothing about what a country means for an application - a nationality, a place of residence, a shipping-destination are all the same choice to it.

## Development

This repository implements the common project structure. The whole pipeline (build, linting, testcases) runs with:

```
task bb
```

The demo-application which shows the component is started with `task rd`.

Besides the unit-tests the repository has visual-regression-tests which render the component in chromium, firefox and webkit and compare the result with the baseline-images in `NgxCountrySelector/Other/Resources/VisualRegressionBaselines`. They run inside a container so that the result is reproducible independently of the operating-system. After an intended change of the appearance the baseline-images are regenerated with `task uvrb`.
